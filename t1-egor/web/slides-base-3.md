# Слайд 16. Доступность — это стандарты

## WCAG — Web Content Accessibility Guidelines

- Международный стандарт W3C
- WCAG 2.0 → 2.1 → 2.2
- WCAG 3 — в разработке
- Уровни соответствия: A, AA, AAA

<!--
Заметки докладчика:

- WCAG — международные рекомендации W3C с проверяемыми критериями доступности веб-контента.
- Ветка WCAG 2 включает уровни A, AA, AAA. WCAG 2.2 опубликован; WCAG 3 остаётся разрабатываемым документом.
- Целевой уровень выбирают по применимым требованиям. Не стоит считать AAA обязательным универсальным уровнем для любого сайта.

Справка — не для произнесения:
AAA не является общей обязательной целью для всех сайтов; WCAG 3 — проект.

Источники и применимые критерии:

# Слайд 19. Почему «глазика» недостаточно

## Доступность ≠ версия для слабовидящих

- Не решает проблемы незрячих пользователей
- Не гарантирует управление с клавиатуры
- Не обеспечивает понятность содержимого
- Не заменяет доступность основного интерфейса

<!--
Заметки докладчика:

- Панель настройки изображения не исправляет недоступную клавиатурную навигацию, семантику и непонятный сценарий.
- Если человек не видит экран, увеличение шрифта не решит его задачу. Для когнитивных трудностей одного масштаба тоже мало.
- Поэтому отдельный режим не равен доступности всего продукта.

Справка — не для произнесения:
WCAG допускает conforming alternate version при условиях стандарта; не заявлять общего запрета альтернативных версий.

Источники и применимые критерии:

# Слайд 39. Не только фирменные цвета

## Windows High Contrast / Forced Colors

- Системные цвета заменяют цвета интерфейса
- `box-shadow` отключается: границы и фокус могут исчезнуть
- Границы — через `border`, фокус — через `outline`
- Проверяйте разные режимы отображения

```css
.button { border: 2px solid transparent; }
.button:focus-visible {
  box-shadow: 0 0 0 3px #6554c0;
  outline: 2px solid transparent;
  outline-offset: 3px;
}
@media (forced-colors: active) {
  .button { border-color: ButtonText; }
  .button:focus-visible { outline-color: Highlight; }
}
```

<!--
Заметки докладчика:
