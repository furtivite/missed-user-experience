## Спикер

**Егор Левченко** — frontend-разработчик в RWB Участие. Занимается цифровой доступностью сайтов и приложений, участвовал в запуске «Доки».

## Как открыть веб-версию

В репозитории откройте `web/index.html` двойным щелчком в браузере. Сервер и подключение к интернету для показа не нужны; при копировании сохраняйте папку `web` целиком.

Если вы скачали `t1-egor-web.zip`, сначала распакуйте архив, затем откройте находящийся внутри `index.html`. Интернет потребуется только для перехода по внешним ссылкам.
