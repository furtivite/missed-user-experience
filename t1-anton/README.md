## Как открыть веб-версию

В репозитории откройте `web/index.html` двойным щелчком в браузере. Сервер и подключение к интернету для показа не нужны; при копировании сохраняйте папку `web` целиком.

Если вы скачали `t1-anton-web.zip`, сначала распакуйте архив, затем откройте находящийся внутри `index.html`. Интернет потребуется только для перехода по внешним ссылкам.
